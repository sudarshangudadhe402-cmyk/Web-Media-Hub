==================================================
SECTION 1: CUSTOMER SOURCE TRACKING
==================================================

Purpose:
Allow admins to create marketing campaigns and automatically track where customers come from.

Features:

1. Create Campaign Form

Fields:

- Source Type (Dropdown)

Source Options:
- Instagram
- Facebook
- WhatsApp
- Google
- SMS
- Direct
- Other

Optional:
- Generate QR Code (Toggle)

Button:
- Create Campaign

==================================================
AUTO GENERATED TRACKING LINK
==================================================

When admin clicks Create Campaign:

Automatically generate a unique tracking link.

Example:

Base URL:
https://{admin-subdomain}.domain.com

Generated URL:
https://shopname.domain.com?source=instagram&campaign=summer_sale

or

https://shopname.domain.com?source=whatsapp&campaign=eid_offer

Rules:
- source comes from dropdown
- campaign comes from campaign name
- campaign should be converted into URL-safe slug

Examples:
"Summer Sale" → summer-sale
"Eid Offer 2026" → eid-offer-2026

Display:

Campaign Name
Source
Tracking Link
Copy Button

==================================================
QR CODE GENERATION
==================================================

If Generate QR Code is enabled:

Automatically create QR code for the tracking link.

Display:
- QR Preview
- Download QR Button

Store QR image URL if needed.

==================================================
CUSTOMER SOURCE TRACKING LOGIC
==================================================

When a visitor opens a tracking link:

Example:
?source=instagram&campaign=summer-sale

Store:

source = instagram
campaign = summer-sale

Use:
- local storage
- cookie
- session

until customer signs up or joins loyalty program.
