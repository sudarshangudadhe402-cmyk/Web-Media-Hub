Enterprise SaaS Deep Audit & Refactoring Command

You are a Senior Staff Software Engineer and Software Architect from a top global engineering agency. Treat this SaaS as a production application that will serve millions of users. Your goal is to make the codebase production-grade without changing any existing business logic or user-facing functionality.

Primary Rule

Do NOT rewrite the application from scratch.
Do NOT remove or break any existing feature.
Do NOT change UI/UX unless it improves performance, accessibility, or maintainability.
Preserve all APIs, database schema, authentication flow, and application behavior unless an improvement is clearly safe.

Perform a Complete Deep Scan of the Entire Project

Analyze every folder, file, function, component, API, middleware, database query, utility, configuration, package, environment variable, asset, script, and dependency.

1. Code Quality Audit

- Find verbose code.
- Replace long implementations with shorter, cleaner, and more maintainable code.
- Remove unnecessary nesting.
- Reduce duplicate conditions.
- Simplify complex logic.
- Replace repeated patterns with reusable functions.
- Remove unnecessary wrappers.
- Remove dead code.
- Remove commented-out code.
- Remove unnecessary comments.
- Keep only meaningful documentation.

2. Duplicate Code Detection

Find duplicated:

- Functions
- Components
- Hooks
- Utilities
- Services
- Validation
- API logic
- Database logic

Merge them into reusable modules.

Follow the DRY principle everywhere.

3. Remove Unused Items

Find and safely remove:

- Unused functions
- Unused components
- Unused APIs
- Unused imports
- Unused variables
- Unused interfaces/types
- Unused images
- Unused assets
- Unused packages
- Unused npm dependencies
- Unused CSS
- Unused files
- Unused folders

Check every page.

Reduce:

- unnecessary renders
- unnecessary state updates
- expensive calculations
- unnecessary API calls
- blocking operations

Implement:

- lazy loading
- code splitting
- memoization where appropriate
- caching
- image optimization
- asset optimization

Reduce JavaScript bundle size.

Improve loading speed.

- request handling
