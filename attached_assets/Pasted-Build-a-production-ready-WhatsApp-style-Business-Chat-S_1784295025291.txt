Build a production-ready WhatsApp-style Business Chat System inside our existing SaaS. Do not create a separate app. The chat must match the existing design system, authentication, database, and architecture.

User Roles

Customer

- Can chat only with the owner of the store they are interacting with.
- Cannot message other customers.
- Cannot message other stores unless a conversation is initiated through that store.
- No chat search feature.

Store Owner

- Can chat with all customers of their own store.
- Can search chats by customer name, phone number, or message content.
- Cannot access chats belonging to other stores.

Business Features

Product Card

Every product card must contain a "Message on WhatsApp" button.

When clicked:

- Open chat with the correct Store Owner.
- Automatically insert product context into the conversation.
- Product card should appear inside the chat.

---

Order Creation

Store Owner can create an order directly from chat.

Order should automatically appear in conversation with:

- Order ID
- Product(s)
- Quantity
- Total Amount
- Payment Status
- Order Status

---

Booking

Booking confirmations must automatically appear in chat.

Also send automatic messages for:

- Booking Confirmed
- Booking Cancelled
- Booking Rescheduled
